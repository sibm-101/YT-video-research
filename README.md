# Viral Idea Engine

A YouTube video idea discovery and validation engine. Finds what's working in any niche, generates new ideas, and stress-tests each one against real YouTube data.

## Setup (3 steps)

1. **Start the engine** — double-click `Start Engine (Mac).command` on Mac or `Start Engine (Windows).bat` on Windows. It sets up everything automatically and opens your browser.

2. **Complete the setup wizard** — enter your Anthropic API key and YouTube Data API key (the wizard includes step-by-step instructions for creating the YouTube key). Both fields have a **Test Connection** button so you know they work before saving.

3. **Create a niche and add research** — on the Dashboard, create a niche (e.g., "Dark History"), then go to Add Research and paste some YouTube channel URLs. Click Analyze, then go to Find New Ideas.

---

**Requirements:** Python 3.11 or newer. No other software needed.

**First launch:** Takes ~1 minute to install packages. After that, starts in seconds.

**Stopping the server:** Close the terminal / command prompt window.
