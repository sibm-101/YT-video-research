Step 1 of 3: Anthropic API Key

The engine uses Claude AI to generate and score ideas. You need an Anthropic API key.

Get a key at console.anthropic.com — create an account and go to API Keys.
Step 2 of 3: YouTube API Key

Used to pull channel data and validate ideas against real YouTube performance.

▸ How to get a YouTube API key (click to expand)
  1. Go to console.cloud.google.com and sign in
  2. Create a new project (or select an existing one)
  3. Click APIs & Services → Library
  4. Search for "YouTube Data API v3" and click Enable
  5. Click APIs & Services → Credentials → Create Credentials → API Key
  6. Copy the key and paste it below
Step 3 of 3: Reddit (Optional)

Reddit can seed the engine with proven topic demand from upvoted posts. This is optional — you can skip it and enable it later in Settings.
